# 增量 14：按钮规范与统计基线

2026-10-23。按照本轮截图先更新 HTML 设计稿 v5，再调整 GPUI 实现。品牌仍沿用已确认的 v4 等距图标；原始批准截图保留。

## 本轮变更

- 统计数值与 `/ N 个容器`、`%`、`GiB` 使用统一行框与基线。GPUI 的嵌套 Div flex baseline 会落在线框底部，因此抽出 `controls::metric_value`，同时用于顶部统计和详情指标。数据仍来自运行时采样。
- 新增共享 `ControlStyle`：普通按钮 32 pt，密集操作 28 pt，行内图标 24 pt；图标按钮显式约束宽高。列表的重启和更多均为 28×28，停止/启动为 28 pt 高，统一 6 pt 间距；排序图标为 24×24、4 pt 间距。检查并调整日志、配置、镜像、任务和表单操作，保留导航与页签的独立高度。
- 停止使用红色文字、浅红背景与红色细边框，亮暗色分别取语义颜色；设置与刷新使用带边框的 32×32 图标按钮。设置位于搜索右侧。
- Logo 添加 1 pt 细边框；标题与工作空间说明间距缩至 2 pt。环境入口将图标、名称、斜线、运行时、展开箭头分开布局，主间距 8 pt。
- 删除全局底栏。详情底部的容器身份/复制操作和表单提交栏仍有明确用途，保留。
- 环境管理采用 240 pt 环境列表与运行时信息分栏，窄窗口上下排列。运行时能力改为两列，保留不可用原因；边框随环境列表内容高度。添加环境移入页面标题操作区，页面刷新会请求诊断。
- 原型同步上述修改、配置分组、环境菜单与镜像多选；拆分环境/镜像脚本。清除旧响应式规则，避免窄窗隐藏工作空间名称、内存统计或操作。终端在当前实现中不可用，原型对应入口同样禁用。
