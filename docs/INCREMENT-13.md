# 增量 13：原型对齐、环境切换与镜像多选

2026-10-23。以 `.agents/design/prototype-approved-light.jpg` 和原型 CSS 为基准，重做原生列表、导航和详情的排布。采用用户本轮明确调整：删除侧栏底部运行时块；设置移到搜索右侧；顶部环境切换，侧栏管理分组进入环境管理。

## 实现

- 品牌图与批准的 v4 原型资产 SHA-256 一致。修正 36 pt 图标位置、文字行高和标题/描述间距；侧栏 208 pt，中等窗口 184 pt，小于 900 pt 使用 64 pt 图标栏。
- 54 pt 顶栏、24 pt 页面标题、四等分统计、32 pt 搜索/工具栏、36 pt 表头、62 pt 列表行。详情在宽度 1280 pt 起并排，宽度 308 pt，1550 pt 起 340 pt；窄窗口单页详情可返回。
- 容器支持当前筛选结果的全选/部分选中/取消选择，最多 32 项；保留筛选外已选对象。行末补齐重启与更多操作，详情增加端口复制和收起图标。
- 统计使用实际采样的 CPU 与内存用量；不能把资源配置上限当作当前用量，缺失/过期数据不计为零。详情折线只画实际收到的最近 60 秒样本，内存显示配置上限。
- 详情使用轻量下划线页签，单项最大 90 pt，避免中等窗口过度拉伸。配置改成紧凑的标签/值行，按运行参数与资源分组；刷新与复制 JSON 收到标题右侧。创建表单改为固定底部操作的右侧面板，保留高级配置、秘密输入和创建后启动；展开入口靠左排列，秘密与启动参数输入使用统一高度。
- 环境菜单连接真实 WorkspaceHost：本机、演示、已绑定远程 Agent 可切换；保留各自列表选择、筛选、操作历史与后台队列，非当前环境暂停日志/统计采样。环境管理可导入已有绑定的控制端文件夹，目录只保存路径与 Agent 标识。共享 RemoteProfile 保持独占锁，多个 Agent 不会重复锁定同一配置目录。
- 镜像支持多选/全选/部分选中、批量复制引用和批量删除，最多 32 项。先有界读取详情，冻结 reference/digest，列出可删除项及跳过原因，再确认提交；被运行或停止容器引用、身份变化、读取失败与正在处理的项目不会提交。执行前 provider 再核验引用/身份，每项结果进入公共任务队列；跳过项继续保留选择，离线时仍可复制，写操作禁用。
- 多选算法抽为共享 selection 模块；镜像列表、批量流程、后台读取，环境管理/切换，容器动作和创建表单均拆分成较小文件。
