# 环境管理重设计 · v6.1

2026-10-23。原型与原生环境管理已同步迭代。实现及验收边界见 [增量 18](../docs/INCREMENT-18.md)。

## 入口与布局

主导航「管理 → 环境管理」。默认查看「开发工作站」示例，顶部工作环境仍为「演示工作空间」。左侧单击仅查看；详情按钮或菜单的「切换到此环境」才更改工作环境。左侧当前环境标识与选中背景含义不同。

列表宽度随窗口为 224 / 192 / 176 px，右侧填满剩余区域；上下边界相同、分别滚动。主机标题含名称、连接状态、主机名、运行时版本和编辑入口。系统信息不做独立大卡片。运行时能力折叠，保留本机离线服务启动入口。

主机资源用一个细边框区域呈现四个指标，≥1024 px 应用宽度时四列，否则两列。容器概览下接连接信息；详情内部滚动，页面标题与环境列表持续可见。

## 字段与语义

| 区域 | 内容 | 展示约定 |
| --- | --- | --- |
| 主机 | 主机名、系统 / 架构、处理器 / 核数、硬件、运行时间 | 来源是所选目标主机，不是控制端设备 |
| CPU | 整机利用率、趋势 | 全部核心归一到 100%，不沿用容器单核百分比 |
| 内存 | 已用 / 总物理内存、趋势 | 容量单位 GiB，辅助值与主值同基线 |
| 网络 | 接收速率、收发两条趋势 | MB/s；发送使用虚线并保留文字图例 |
| 磁盘 | 已用 / 总容量、使用比例、读写趋势 | 容量与 I/O 分开标注，不混成同一指标 |
| 容器 | 运行、停止、状态未知 | 点击分类可查看对应容器 |
| 健康检查 | 健康 / 已检查、不健康、未配置 | 未配置不当作健康；停止和异常退出不计入已检查分母 |
| 连接 | 目标 / 中继地址、策略、请求耗时、最近采样 | 中继保留目标身份与备用直连地址；仅中继策略注明直连停用 |
| 身份 | Agent 版本、绑定时间、公钥指纹 | 只读，复制的是指纹，不展示私钥 |

原型提供本机、演示工作空间、局域网开发工作站、中继构建节点、离线测试节点。默认主机图表每 2 秒变化；表单可改为 5 / 10 秒。图表采样带时间戳，范围为最近 1 / 5 分钟；暂停和离线冻结曲线。刷新页面会恢复全部示例数据。

## 状态与交互

- 在线：资源趋势更新，请求耗时和最近采样可见。
- 离线：保留最后记录并注明采样时间；健康区显示待更新，趋势转为中性。超时检查不显示「身份验证失败」，因为尚未到达验证阶段。
- 修改连接：保存地址后显示待验证，原 Agent 指纹保留；后续检查成功才恢复在线。真实实现必须拒绝身份不匹配，并允许用户修正地址，不能静默重新绑定。
- 搜索：原型过滤名称、主机名与备注；原生过滤名称与目标标识。不会暗中改变当前工作环境或右侧目标。
- 编辑：名称必填且不能重名。远程要求有效 wss 地址，拒绝 URL 内账号、密码、查询和 fragment；直连 / 中继策略禁用不相关输入。取消不保存。
- 右键：查看、切换、编辑、复制、检查；远程额外提供移除。目标绑定到点中的行。原型菜单支持键盘导航；原生菜单复用 GPUI 组件并验证右键打开、点击和取消。
- 移除：确认中说明只移除此设备列表条目，不停止容器、不解除 Agent 所有者绑定。移除当前环境后回到演示工作空间。

## 数据与实现边界

主机遥测使用公共领域模型，由本机采集器 / Agent 分别产生，Native 与 Node 使用同一契约。已按主机身份、资源采样、容器健康汇总、连接状态、可编辑配置拆分模块，避免继续扩充单一环境视图。

采样字段必须包含目标环境 ID、采样时间、数据来源与可用性。若平台无某项采样，显示「暂不支持」或「—」；连接超时不以 0% 代替缺失数据。健康需保留 healthy / unhealthy / starting / 未配置 / 不支持 / 未知，原生与原型展示其中主要状态。

主机遥测独立于容器 stats，已实现真实 OS 采样、鉴权后的 RPC、采样节流和连接编辑持久化。延续现有首次绑定 / 设备授权关系；环境配置只引用凭据句柄，不存储或在 UI 分发私钥。

原型本身仍使用示例数据；真实 OS 采样与隔离加密直连/中继由独立测试验证。公网连接与 Native / Web 密钥同步不在本轮验收内。其他资源页继续使用既有容器 / 镜像示例集合。

## v6.1 精简

移除重复的页脚说明、列表操作提示和健康检查解释段。保留示例、离线、采样暂停与绑定身份提示。移除无后端支持的启动自动连接选项；当前按查看目标采样，离开页面后停止主机采样。远程协议按请求建立认证连接，连接耗时包含身份验证，不展示虚构的长连接时长或心跳。
