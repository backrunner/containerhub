# ContainerHub UI 与交互设计

> 2026-10-23 · v6.0 环境管理主机概览，沿用 v4 等距图标。设计方向：科技蓝、紧凑、原生、以操作为中心。与 PLAN.md 配套；HTML 仅用于评审，最终用 GPUI 实现。

## 1. 设计主张

打开应用直接看到容器。名称、状态、端口和启停操作在同一行；详情与日志在旁边打开，保持列表位置。环境身份常驻顶部，长任务进入统一任务中心，失败保留上下文和恢复动作。

视觉使用冷灰白与深石墨表面，钴蓝作为品牌与主操作色。蓝色集中在主按钮、当前导航、焦点与少量趋势线；表格正文保持中性。细边界区分区域，避免整屏卡片、装饰渐变和大面积状态色。首发简体中文与英文文案结构兼容，名称、镜像和命令保留原文。

应用图标使用三枚蓝色玻璃容器以等距视角堆叠，磨砂顶面、柔和倒角与层间阴影体现独立模块的组合。图标放在珍珠白底面上，侧栏、评审栏与 favicon 使用同一静态母图，网页通过统一圆角裁切。v2 CH 字形与 v3 开口模块图形已停用。资产与生成提示词见 [品牌说明](design/brand/README.md)。本次为生成的 PNG 设计稿，原生分层材质与系统外观模式另行制作。标题栏只显示当前环境，侧栏承担完整品牌，避免同一区域重复堆叠名称。

版式遵循统一基线：页面标题与主操作居中对齐；摘要以四列数字和细分隔线呈现，不再配重复的小图表；数值列右对齐；详情中的 CPU 与内存标签、数值、趋势图分别对齐。文案直接描述资源与动作，删除无信息量的口号、重复英文眉题和装饰性标签。

## 2. 信息架构

```text
窗口标题栏：交通灯 / 环境切换 / 搜索 / 带边框的设置齿轮
侧栏：
  容器                       ← 默认页
  镜像
  存储卷
  网络
  [构建]                     ← B 阶段
  [项目与模板]               ← B 阶段
  管理：环境管理 / 任务中心
主区：
  页面标题 + 数量 + 主要操作
  紧凑状态摘要
  搜索、状态筛选、刷新
  资源表格 / 场景空态
右侧：容器检查器（概览 / 日志 / 配置 / 终端）
全局底栏：移除
```

本机 Apple container 与已绑定远程 Agent 使用统一环境入口。v6 原型使用明确标注的本机、直连、中继和离线示例，展示待落地的主机遥测与环境编辑设计；真实连接仍以产品能力为准。Docker、Kubernetes 适配未实现，不展示为已支持的运行时。未来 Kubernetes 使用工作负载、Pod、Service、配置、存储和 Namespace 导航。

## v5.1 控件与对齐约定

控件规范见 [增量 14](../docs/INCREMENT-14.md)，分页与等高布局见 [增量 15](../docs/INCREMENT-15.md)。普通按钮 32 px、密集按钮 28 px、行内图标 24 px；工具栏间距 8 px，行操作间距 6 px。刷新/设置为带边框的 32×32 图标按钮，行内重启/更多均为 28×28。停止为红色语义按钮。Logo 为 36×36，圆角 8 px，1 px 边框；标题/说明间距 2 px。

统计值为 22/28 px 字号/行高，单位为 10/14 px，同一文字基线、6 px 间距；详情数值为 20/26 px。数值与辅助文案不能依赖嵌套布局的默认 baseline。数据缺失显示破折号，不填充原型示例值。环境管理改用 v6 主机概览：224 / 192 / 176 px 环境列表加弹性详情，两栏等高且独立滚动；760 px 窗口仍保持左右结构。

## 5. 主要页面

### 5.1 容器列表

底部分页高 32 px，与表格间隔 12 px；默认每页 10 条，可选 5/10/20/50，显示范围、总数、页码和前后按钮。搜索、筛选、排序重置首页；当前页全选保留跨页选择。双栏占满可用高度，分页底边与详情底边对齐；表格内部滚动，末页不收缩。

顶部是「容器」标题、资源数量与「新建容器」主按钮。其下用一条状态摘要呈现运行/停止/异常数量及资源用量，避免无关 KPI。筛选栏含搜索和状态，默认表格列为：勾选、名称/镜像、状态、CPU/内存、端口、操作。

- 运行中行直接提供「停止」和重启；已停止/异常行提供「启动」。危险删除放在更多菜单。
- 行名称进入详情；行快捷动作不改变当前查看对象。右键操作必须绑定点击的行，不能误用已选中行。
- 选中多行后出现批量工具条，显示具体目标数，保留取消选择；筛选不隐式扩大操作范围。
- 指标无数据时显示破折号和原因；停止资源的 CPU 不应显示历史实时值。
- 端口以 `127.0.0.1:3000` 等明确地址显示；只有已知 HTTP 服务才使用「打开」，其他端口提供复制。

### 5.2 详情检查器

头部：容器名称、镜像、状态、启停动作。Tab：概览、日志、配置、终端。

- **概览**：资源趋势/用量、运行时间、端口、网络、挂载；可复制标识，字段单位清楚。图表注明 CPU 分母和内存来源；无指标时只展示可用信息。
- **日志**：时间/等级/内容，跟随、暂停、搜索、导出；滚动离开底部自动暂停跟随，并出现「回到最新」。boot log 独立切换。
- **配置**：用户可读分组与原始 inspect 视图；Secret 遮蔽，复制默认同样遮蔽；编辑显示「需重建」及变更预览。
- **终端**：显式「连接终端」后启动 PTY；选择 shell/用户、尺寸同步、退出码、断开。停机、无 shell、权限失败分别解释。

原型终端只显示模拟会话，不执行输入。真正 PTY 的滚动、ANSI、IME、复制粘贴、Ctrl-C 和 resize 都需原生验证。

### 5.3 新建容器

采用右侧宽抽屉，基础与高级设置渐进展示，底部固定「取消 / 创建并启动」。

1. **镜像与身份**：镜像搜索/手动输入、名称、平台；显示本地镜像命中与需拉取状态。
2. **资源与连接**：CPU、内存、端口映射、网络、挂载；端口默认绑定 loopback，公开到 LAN 需明确选择。
3. **进程与环境**：entrypoint/args、workdir、用户、env 与 env-file；Secret 有独立输入与临时显示。
4. **高级**：DNS、只读、capabilities、Rosetta、kernel 等，仅展示当前支持字段；清楚标出实验项。
5. **执行前检查**：名称、端口、路径、镜像平台和数据权限；下方显示拉取/创建/启动阶段。展示可复制的脱敏 CLI 预览，但不让 shell 文本成为真实执行入口。

失败不清空表单。容器已创建但启动失败时显示已创建资源及修复入口，不能让重复提交继续创建副本。

### 5.4 镜像、网络和存储

- 镜像表格：引用、平台、大小、使用关系；拉取主操作，行内更多提供 tag/push/save/delete。构建使用独立任务，不阻塞浏览。
- 存储卷：名称、驱动/来源、容量、引用者；「使用中」可跳转资源。删除显示数据影响，默认保留；备份按钮需要说明是否已停止写入。
- 网络：名称、子网、容器数、DNS；详情展示关联关系和限制。不能用「断开」伪装不支持的动态变更。
- 清理：先选择资源与范围，预览可回收量和依赖，再执行；估计值明确标注，重新核查后允许数量变化。

### 5.5 运行时与任务中心

运行时页呈现引擎版本、服务状态、能力、builder、machine、DNS、磁盘和诊断入口。停止服务要显示会影响哪些容器；不会把「重启应用」与「重启运行时」混用。

任务中心按进行中、失败、全部查看。每项记录环境、资源、动作、阶段、时间、结果，失败展开到逐资源错误。操作完成后可查看结果；没有确切进度时用阶段与已处理数，不编造百分比。

## 6. 状态设计

| 场景 | 呈现与恢复 |
| --- | --- |
| 初次加载 | 表头稳定、有限骨架、明确正在读取；不先闪空状态 |
| 未安装 | 安装要求、已检测平台、安装指引和重新检测；不伪装空容器列表 |
| 服务停止/离线 | 保留陈旧资源、顶栏状态和最后同步时间，停用写操作；「启动服务/重新连接」 |
| 权限不足 | 具体动作与目标，说明所需授权；保留只读功能 |
| 正常空列表 | 一句解释 +「新建容器」/「拉取镜像」，无虚构使用率 |
| 搜索无结果 | 保留筛选，提供清除；不和未创建资源混淆 |
| 部分失败 | 明确成功/失败/未执行数量；展开失败原因，仅重试失败项 |
| 状态变更中 | 行内忙碌标记和阶段；保持行位置；禁用冲突动作 |
| 数据陈旧 | 标明更新时间/离线；旧数据与实时数据视觉可区分 |
| 不支持/缺插件 | 说明原因和可恢复方式；不呈现可用动作 |
| 目标已删除 | 检查器提示资源不存在，返回列表；不对同名新资源复用旧 ID |
| 删除确认 | 名称、数量、环境、是否含数据；高影响操作要求再次明确目标 |
| 未知结果 | 告知请求已发出但结果未确定，提供对账入口，避免重复写入 |

## 7. 键盘、辅助功能与动效

- `⌘K` 命令面板；`⌘N` 新建；`⌘R` 刷新；`⌘F` 聚焦当前页搜索；Escape 关闭浮层并回到触发控件。
- 表格方向键选择、Enter 打开、Space 勾选；常用动作必须有可聚焦按钮和可读名称。
- 快捷键只在正确上下文触发：终端输入不被全局单字符命令截获；输入法组字时不误触操作。
- 抽屉/对话框管理焦点、焦点循环与关闭后恢复；VoiceOver 可读资源名称、状态、动作和逐项结果。
- 所有颜色对比与高对比模式实测；正文目标 WCAG AA，Reduce Motion 关闭不必要过渡。
- 动效仅用于状态反馈和抽屉过渡（120–180 ms）；不使用持续闪烁状态灯或背景动画。

## 8. GPUI 落地约定

| 原型结构 | GPUI 组件边界 |
| --- | --- |
| 应用外壳、环境选择 | `AppShell` / `EnvironmentSwitcher` |
| 侧栏与页面头 | `Sidebar` / `PageHeader` |
| 资源列表 | `ResourceTable` + 版本化不可变 snapshot + 稳定 key |
| 行操作与批量条 | `ContainerActions` / `BatchActionBar` |
| 详情检查器 | `ContainerInspector` / 按 Tab 懒加载内容 |
| 日志与终端 | 独立模型和缓冲，渲染虚拟化；订阅生命周期明确 |
| 新建和危险确认 | `CreateContainerSheet` / `ImpactConfirmation` |
| 任务与错误 | `OperationCenter` / `InlineError` / 有限 Toast |
| 主题 | `ThemeTokens`，按 semantic role 使用 |

GPUI 渲染只读取 UI 状态。网络、CLI、SQLite、日志解析不在 render/update 回调中阻塞。对资源更新按需通知，合并高频指标；不要每次采样重建整个表格。窗口、菜单、tray 与 command palette 复用同一套应用命令，不产生不同的启停逻辑。

## 9. 设计验收与原型覆盖

交互原型覆盖：容器列表、概览、镜像/卷/网络、运行时、任务中心、右侧详情四个 Tab、新建、批量操作、删除确认、主题、搜索、命令面板、空状态、运行时离线与部分失败。

后续需补原生细化：完整高级创建表单、registry 登录、构建编辑器、machine 管理、DNS/kernel 权限面板、重建差异、卷备份、远程注册与 Kubernetes 专用页面。功能计划包含这些工作，但本次不将所有页面都绘制成高保真稿。

评审看四件事：关键动作是否无需寻找；名称和状态是否一眼可读；失败能否直接恢复；复杂功能能否扩展而不压垮首版布局。截图仅证明 HTML 设计稿的视觉呈现，原生渲染与性能另行验证。

## v5.3：端口重建与紧凑操作

行操作组固定 136 pt，启停 64×28，重启/更多 28×28，间距 8 pt。内存上限与单位同为小字号基线后缀，如 `48 MiB / 512 MiB`。端口映射作为编辑入口，旁边保留独立复制按钮；多条映射显示数量。

端口编辑弹窗 580 pt，输入框及协议控件高 32 pt，字段间距 8 pt。支持增删行，内容超高时内部滚动；底部取消/重建按钮右对齐。确认使用红色危险风格“重建”，提示停止并删除原容器、可写层丢失、挂载数据保留、恢复运行状态、失败不回滚。原型仅模拟重建，不连接本机运行时。

## v5.4：详情栏收起

收起按钮为 32×32 pt 描边图标按钮，与左侧容器图标顶部对齐；左右内边距均为 17 pt。宽窗口以 200 ms 平滑收起详情列，同时收拢 20 pt 栏间距并扩展列表，详情内容保持原宽度并淡出，避免压缩换行。窄窗口淡出详情后返回列表。遵循系统减少动态效果设置，关闭动画时立即切换。收起过程中重新选择容器会取消关闭，完成后才释放详情订阅。

## v5.5：离线服务启动

环境管理在 CLI 信息下增加服务状态区，内边距 12 pt、圆角 7 pt，状态与说明在左、启动/核对按钮在右；沿用既有主题与紧凑控件。本机离线且能力允许时显示“启动服务”，执行中禁用，结果未知时只提供“核对结果”。资源页离线提示通过“检查环境”进入此处。

确认弹窗 540 pt、内边距 24 pt，说明启动后台服务与手动完成首次安装/权限；取消与启动按钮右对齐、高 32 pt、间距 8 pt。状态区与确认都覆盖亮暗色和最小 760×560 窗口。原型入口 `?page=runtime&scenario=offline`，未知状态 `?page=runtime&service=unknown`；示例启动不会操作本机。实现和独立验证边界见 [增量 17](../docs/INCREMENT-17.md)。


## v6.0：环境管理主机概览

本次先交付交互原型，原生应用仍为增量 17。详细布局、状态与数据契约见 [环境管理重设计](ENVIRONMENT-REDESIGN.md)，浏览器验证见 [设计验收](design/VALIDATION.md#2026-10-23--v60-环境管理重设计)。

- 环境列表按本机 / 远程分组，支持搜索、行右键、更多按钮及 Shift+F10。查看主机与切换工作环境分离；右键始终操作点中的行。
- 详情显示主机、系统、处理器、内存容量、运行时间；CPU、内存、网络、磁盘读写为滚动趋势，支持 1 / 5 分钟与暂停。CPU 按整机 100% 归一，内存与磁盘容量采用斜线辅助数值。
- 容器运行状态与健康检查独立统计。未配置检查、已停止均不计为健康；可点击分类查看容器。离线图表冻结，最后采样与健康状态明确标为历史记录。
- 连接路径区分本机、直连、中继，展示地址、延迟、心跳、连接时长、Agent 版本与绑定指纹。中继同时展示目标地址。绑定身份只读，编辑地址后进入待验证状态。
- 编辑使用 modal + form：名称、备注、采样频率；本机 CLI 路径；远程连接策略、目标 / 中继地址、自动连接。表单内部滚动，操作栏固定，保存后更新对应行。
- 工具栏图标 32×32；列表更多 28×28（紧凑布局 24×24）；主机操作间距 8 px。宽窗口资源四列，窄于 1024 px 时为两列；不新增全局 footer。

所有新增主机、健康与连接数据均为设计样本；检查连接、启动服务、修改配置只改变页面内存状态。没有从浏览器读取运行时、发起远程握手或同步密钥。
